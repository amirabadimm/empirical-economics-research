# Workflow — گواهی سپرده گندله سنگ‌آهن

- منبع: API رسمی CDC بورس کالای ایران، بازار ۲۲.
- شروع سری: 1404/07/28 برابر 2025-10-20.
- کد قدیم: `CD1IOP0001`؛ کد جدید: `IronOrePlt`؛ `CommodityID=28`.
- collector: `src/pellet/collectors/certificate.py`.
- منطق مشترک: `../../shared/ime_data/certificate_collector.py` نسبت به ریشه workspace؛ هنگام انتقال پوشه `shared/ime_data` نیز لازم است.
- CSV: `data/raw/certificate/pellet_certificate_raw.csv`.
- قواعد: حفظ روز صفر، snapshot کامل، merge بر تاریخ، refresh چهارده‌روزه، نوشتن atomic.
- validation: schema کامل، تاریخ یکتا، کد/شناسه/شرح ثابت، مقادیر نامنفی و تطبیق
  `TradesValue / TradesVolume` با `TodaySettlementPrice` در روزهای معامله.
- معیار قیمت در تحلیل‌های آینده `TodaySettlementPrice` است و نسبت ارزش به حجم فقط validation خواهد بود.
- وضعیت 2026-08-10: ۲۵۲ ردیف تا 2026-08-09؛ ۱۸۲ روز معامله مثبت.

اجرای عادی از داخل `commodity/pellet`:

```powershell
python .\src\pellet\collectors\certificate.py
```

اجرای کامل فقط برای بازسازی یا audit:

```powershell
python .\src\pellet\collectors\certificate.py --full-refresh
```

اجرای incremental دوم بدون افزایش تعداد ردیف و تمام کنترل‌های schema، تاریخ،
OHLC، کدها، CommodityID و قیمت تسویه موفق بوده است.

داده خام بازار فیزیکی اکنون جمع‌آوری و اعتبارسنجی شده است؛ underlying نهایی،
benchmark پردازش‌شده و حباب هنوز انتخاب یا تولید نشده‌اند.

و فقط برای معاملات دارای `Quantity > 0` و `Price > 0` انجام شد. هیچ فایل داده‌ای
جدید تولید و هیچ فیلتر نهایی تصویب نشد.

- فقط یک نام کالا: «گندله سنگ آهن»؛ واحد تن و بسته‌بندی فله؛
- ۱۳ تولیدکننده و ۱۳ نماد؛
- سهم حجمی گل‌گهر ۲۹٫۱۹٪، گهرزمین ۲۳٫۷۲٪، چادرملو ۹٫۵۴٪، اپال پارسیان
  سنگان ۹٫۵۳٪ و توسعه فراگیر سناباد ۷٫۹۱٪؛
- قراردادها: نقدی ۴۸٫۲۶٪، سلف ۳۹٫۴۴٪، نقدی مچینگ ۷٫۶۰٪ و سلف مچینگ ۴٫۷۰٪؛
- ۹۷٫۵۵٪ حجم در تالار صنعتی.

نتیجه: نام محصول یکدست است، اما مانند مس یک تولیدکننده منفرد غالب نداریم. پیش از
ساخت benchmark باید مشخصات کیفی گواهی، عیار و شرایط تحویل با عرضه‌های تولیدکنندگان
تطبیق داده شود. گزینه اولیه پس از تأیید همگنی، سبد تولیدکنندگان واجد شرایط با قیمت
موزون حجمی روزانه و تفکیک نقدی از سلف است؛ این گزینه هنوز تصمیم نهایی نیست.

منبع اصلی پیشنهادی برای collector آینده API عمومی رسمی بورس کالاست. BrsApi فقط
برای کشف، کنترل متقابل یا fallback نگه داشته می‌شود و هیچ کلیدی در پروژه ذخیره نشود.

## مرحله جاری: collector خام بازار فیزیکی

فایل `src/pellet/collectors/physical.py` ساخته شد و از منطق مشترک
`shared/ime_data/ime_physical_collector.py` استفاده می‌کند. دامنه فعلی عمداً
گسترده است: تطابق دقیق نام نرمال‌شده «گندله سنگ آهن»، بدون محدودیت تولیدکننده،
نماد، قرارداد، تسویه یا حجم. عرضه‌های مقدار صفر در raw حفظ می‌شوند و snapshot کامل
ماهانه پیش از فیلتر نیز آرشیو می‌شود.

خروجی پس از نخستین اجرای تأییدشده:

```text

```

رفتار collector افزایشی و atomic است: اجرای نخست از 1386/01 تا ماه جاری را جست‌وجو
می‌کند و اجرای عادی بعدی دو ماه انتهایی را بازخوانی و جایگزین می‌کند.

یادداشت اجرا: در اجرای کامل نخست، `curl` ویندوز پس از تعدادی درخواست با خطای
Schannel `SEC_E_NO_CREDENTIALS` روبه‌رو شد، در حالی که همان warm-up و POST با HTTPS
پایتون پاسخ 200 و schema کامل داد. منطق مشترک اکنون فقط هنگام شکست curl به
`requests` fallback می‌کند؛ URL، payload، منبع داده و قواعد آرشیو تغییر نکرده‌اند.

### نوت‌بوک بررسی نقدی شرکت‌ها

فایل `notebooks/01_physical_analysis.ipynb` برای تصمیم‌گیری اکتشافی ساخته شده است.
در بازبینی 2026-08-09 خروجی‌ها و execution countهای قابل‌بازتولید آن برای Git پاک
شدند؛ اجرای مجدد notebook برای مشاهده نمودارها لازم است. دامنه آن
فقط قراردادهای «نقدی» و «نقدی (مچینگ)» دارای
`Price > 0` و `Quantity > 0` است. `Price` معیار قیمت منبع باقی می‌ماند و رابطه
`Price = TotalPrice / Quantity` با تلورانس گردکردن ۰٫۵۱ ریال کنترل می‌شود. در
۱٬۰۵۷ ردیف این دامنه، بیشترین اختلاف ۰٫۵ ریال بود.

نوت‌بوک قیمت موزون هر شرکت/نماد را در هر روز ابتدا به تفکیک قرارداد و سپس به‌صورت
ترکیبی نقدی+مچینگ می‌سازد؛ موزون‌سازی فقط میان ردیف‌های همان شرکت و همان روز انجام
می‌شود. نمودار شرکت‌های اصلی، اختلاف نقدی و مچینگ، فاصله هر شرکت از قیمت موزون کل
همان روز، مقایسه مقطعی یک تاریخ انتخابی و جدول پراکندگی روزانه برای تصمیم underlying
در آن قرار دارد. هیچ خروجی نوت‌بوک در raw ذخیره یا CSV خام بازنویسی نمی‌شود.
